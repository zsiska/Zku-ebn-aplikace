# Zkouška

Zkušební aplikace pro iPhone (SwiftUI): počítadlo a poznámka, obojí se ukládá v telefonu.

## Instalace na iPhone

1. Po každé změně ve složce `ios/` sestaví GitHub Actions soubor `Zkouska.ipa`.
2. V Safari na iPhonu otevřete **Releases → ios-latest** a stáhněte `Zkouska.ipa`.
3. V AltStore: **My Apps → +** a vyberte stažený soubor.
